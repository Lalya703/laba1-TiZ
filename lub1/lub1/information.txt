Лабораторная работа №1.

!ВАЖНОЕ!
Запуск производится через терминал, командой: python p6_main.py 01_internet_magazin.csv

1. Фролов Павел — p1_load_clean.py
    Первичный загрузка данных и чистка текста.
Загружаем файл таблицы. Проверяем качество. С помощью louad_data(path) - 
смотрит: размер табл, тип данных, кол пропусков. Очищаем текст от шума tidy(text) -
деает: нижний регистр, схлопывает повторы знаков, удаляет мусорные символы, убирает лишние пробел.

2. Корпачева Ульяна — p2_entities.py
    Извлечение сущностей регулярными выражениями.
find_all(text) — сканирует исходный текст сообщения с помощью словаря регулярных выражений PAT.
Находит и вытаскивает в виде списков все скрытые URL-адреса, e-mail, номера телефонов, даты и цены для их раздельного хранения.

3. Арканова Ксения — p3_anonymize.py
    Защита и коденфициальность.
hide(text) — берёт шаблоны из p2 и заменяет реальные личные данные в тексте на безопасные текстовые заглушки из словаря MARK.
(например, реальный телефон превращается в [PHONE], ссылка — в [URL]).

4. Корсеева Доминика — p4_tokens.py
    Нарезка текста и сортировка.
split_words(text) — удаляет из текста маркеры-заглушки и с помощью регулярного выражения WORD 
вытаскивает только чистые последовательности букв, нарезая предложение на отдельные слова.
drop_stop(words) — сверяет полученные слова со списком STOP (предлоги, союзы, служебные слова вокруг ссылок и цен)
и выбрасывает их, а также удаляет слишком короткие однобуквенные слова.

5. Мендогралова Софья — p5_lemmas.py
    Приведение слов к начальной форме и сборка финальной базы.
make_lemmatizer() — проверяет наличие библиотеки pymorphy3. Если она есть — 
создаёт инструмент для автоматического поиска начальной формы слова (леммы). 
Если библиотеки нет — переключается на ручной запасной словарь LEMMA_DICT (превращает «покупку» в «покупка»).
build_dataset(df) — главный рабочий узел конвейера. Прогоняет каждое сообщение через функции всех ребят 
(find_all, hide, tidy, split_words, drop_stop, lemmatize) и склеивает результаты в одну итоговую таблицу со всеми 13 колонками.

6. Богданова Владислава — p6_main.py
    Анализ, создание отчетов, глава вся кода.
Отслеживает работу файлов р1-р5 , передавая данные из одного скрипта в другой.
Составление рейтинга ТОП-20 самых частых слов ДО очистки  и после очистки с помощью функции top20(words, name).
write_report(out, src, df, counts, t_before, t_after) — собирает всю статистику 
(объём данных, пропуски, количество найденных телефонов/ссылок, таблицы ТОП-20) и записывает красивый итоговый отчёт в файл report.txt.
main() — оркестратор проекта. Настраивает запуск через консоль (argparse), создаёт папки (os.makedirs),
последовательно запускает функции Павла (load_data) и Софьи (build_dataset), считает итоговые рейтинги через свою функцию top20,
подсчитывает скрытые сущности и сохраняет файлы clean_messages.csv, top20_before.csv и top20_after.csv на компьютер.

Краткая схема работы:
1. main запускает код Павла load_data для чтения файла.
2. Программа считает грязный топ слов, используя функции Павла tidy и Доминики split_words.
3. main передает таблицу Софье в build_dataset. Она по цепочке вызывает поиск Ульяны (find_all),
 маскировку Ксении (hide), чистку Павла (tidy), нарезку Доминики (split_words + drop_stop) и делает лемматизацию.
4. Функция Влады main забирает чистый результат, считает итоговые частотности через top20, сохраняет таблицы в CSV
 и просит функцию write_report сделать финальный текстовый отчёт.


 *Файл requirements.txt содержит список всех внешних библиотек(pandas, pymorphy3, pymorphy3-dicts-ru), 
  которые необходимы для корректной работы нашего конвейера.
  Чтобы обеспечить воспроизводимость кода на любом новом компьютере,

  Она автоматически скачает и установит нужные версии библиотек.
